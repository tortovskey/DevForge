# Изменения

## 1.0.0 — 2026-10-31

- Публичный исходный код под MIT; две поставки Windows: IDE и Desktop.
- Web исключён из релизов и команд сборки.
- Шесть тем с общей палитрой Monaco и интерфейса, свои акценты и цвета.
- Раскладки Code, Studio, Focus; перестановка и изменение размеров панелей.
- Расширенные настройки шрифта, отступов, переноса строк, курсора и подсказок.
- Схемы клавиш VS Code и JetBrains, собственные назначения с проверкой конфликтов.
- До 12 профилей, экспорт/импорт JSON и доступная JSON Schema.
- Палитра команд с навигацией клавиатурой; закрытие вкладки сохраняет файл.
- Проверяемая загрузка внешних сред исполнения для сборки из чистого клона.
- Установщики с MIT, сведениями о версии и голубой иконкой кузницы.
